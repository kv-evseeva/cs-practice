## Git и GitHub

#### Основные понятия

**Рабочая папка** - директория на компьютере, в которой ведется работа над проектом (создание, изменение, удаление файлов).

**Индекс** - промежуточная зона между рабочей папкой и git-репозиторием. Сюда командой `git add` добавляются файлы для подготовки к фиксации.

**Коммит** - зафиксированный снимок состояния файлов из индекса, который сохраняется в истории проекта.

#### Разница между Git и GitHub

**Git** - система контроля версий (программа). Позволяет отслеживать и фиксировать изменения локально на компьютере.

**GitHub** - облачный сервис для хранения git-проектов и работы над ними в команде.

Главное отличие: для работы с GitHub необходим интернет.

#### Использованные команды

`git status` - показывает текущее состояние рабочей директории и индекса.

`git diff` - показывает изменения в рабочей папке, которые еще не добавлены в индекс.

`git diff --staged` - показывает изменения, которые уже подготовлены к коммиту.

#### Ветки

**Ветка** - независимая линия разработки. Она позволяет работать, не затрагивая основной стабильный код.

По сути ветка - это подвижный указатель на определенный коммит. При создании нового коммита указатель текущей ветки автоматически перемещается вперед на этот коммит. Предыдущие коммиты остаются в истории, а ветка указывает на самую последнюю версию кода.

**Слияние (merge)** - процесс объединения изменений из одной ветки в другую. Все коммиты, сделанные в исходной ветке, переносятся в целевую.
