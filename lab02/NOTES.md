## Git и GitHub

#### Основные понятия

**Рабочая папка** - директория на компьютере, в которой ведется работа над проектом (создание, изменение, удаление файлов).

**Индекс** - промежуточная зона между рабочей папкой и git-репозиторием. Сюда командой `git add` добавляются файлы для подготовки к фиксации.

**Коммит** - зафиксированный снимок состояния файлов из индекса, который сохраняется в истории проекта.
